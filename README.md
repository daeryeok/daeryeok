# Operating Rules

Build quietly. Keep the working circle almost viciously small.<br>
Put authority where accountability lives.<br>
Test early. Document what matters.<br>
Release only what the evidence supports.

Loosely adapted from Clarence “Kelly” Johnson’s
[14 Rules and Practices](https://www.lockheedmartin.com/content/dam/lockheed-martin/aero/photo/skunkworks/kellys-14-rules.pdf)
at Lockheed Martin’s
[Skunk Works®](https://www.lockheedmartin.com/en-us/who-we-are/business-areas/aeronautics/skunkworks/skunk-works-origin-story.html).
